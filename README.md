# StayFinder

A full-stack accommodation booking platform where hosts list places to stay and guests search, book and review them.

> Status: in development.

## Planned stack
- **Backend:** C#, ASP.NET Core (.NET 10), EF Core, SQL Server
- **Frontend:** React, TypeScript, Tailwind CSS
- **DevOps:** Docker, GitHub Actions

## Planned features
- JWT authentication with roles (Guest, Host, Admin)
- Listings with photos and amenities
- Availability-aware search with filters
- Concurrency-safe booking (no double bookings)
- Reviews for completed stays
